## 📦 INSTALLATION GUIDE

### **Step 1: Install Frontend Dependencies**
```bash
cd frontend
npm install
```

This installs:
- `framer-motion@11.0.0` - Advanced animations
- `gsap@3.12.5` - Timeline animations
- `mapbox-gl@3.1.0` - 3D maps
- `three@0.161.0` - 3D graphics
- `react-spring@9.7.3` - Physics animations
- `@radix-ui/*` - Accessible components
- `cmdk@0.2.0` - Command palette
- `react-dropzone@14.2.3` - File uploads
- `tailwind-merge@2.2.0` - Class utilities
- And more...

### **Step 2: Start Development Servers**

**Backend (already running):**
```bash
# Terminal 1
cd backend
mvn spring-boot:run
# Running on http://localhost:8080
```

**Frontend:**
```bash
# Terminal 2
cd frontend
npm run dev
# Will run on http://localhost:5175
```
